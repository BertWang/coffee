## 2. 網站真正目標

網站不是傳統競選海報搬上網路，而是讓第一次認識曾偉修的訪客，在短時間內理解：

1. 曾偉修是誰。
2. 為什麼投入龍子里。
3. 有哪些人生、工作、創業與公共服務經歷。
4. 對龍子里的理解與行動方向。
5. 過去實際處理過哪些居民問題。
6. 如何聯絡與反映問題。

設計應建立「可信任、有效率、有地方生活感」的印象，避免滿版政治口號、過度宣傳或與一般候選人海報網站同質化。

## 4. 首頁方向與心理進場動線

首頁第一屏保持乾淨、人文與地方生活感，**絕不做成傳統選舉宣傳海報**。

### 關鍵進場順序（心理動線定案）

一進網站**絕不先看到**「龍子里里長候選人 曾偉修」，避免非既有支持者在幾秒鐘內產生防備心或審美疲勞而跳出；而是先引發共同社區未來的共鳴與好奇心：

1. **第一眼大標題**：`龍子里的下一步`
2. **核心金句**：`我們今天做的選擇，決定十年後生活的樣子。`
3. **真實生活影像**：龍子里大順一路、輕軌、住宅街廓的生活場景。
4. **五大生活議題橫幅**：`孩子安心上學｜長輩跟上科技｜交通更安全｜建設有人把關｜小事有人處理`
5. **後置候選人揭示**：`曾偉修，邀請您一起想想龍子里的下一步。`

主要 CTA 以認識人物、地方行動、服務紀錄與聯絡為核心。

## 4.1 手冊轉網頁（Print-to-Web）核心轉換規範

本站架構與內容全面對齊《龍子里的下一步》16 頁 A5 競選小冊（P.1～P.16），但必須遵循「印刷手冊轉化為數位網頁」的互動本質：

- **網頁端零 QR Code 原則**：
  - 實體小冊子的任務是引導居民從紙本「掃碼進入」數位世界，故手冊封底印有 QR Code；
  - 網頁端訪客**本來就已經在數位環境中**，在螢幕上放 QR Code 讓使用者拿手機掃自己的螢幕屬於反直覺的體驗退行。
  - 因此網頁端**絕不產生任何冗餘 QR Code**，全數轉換為原生可互動之按鈕與超連結：
    - 電話：`<a href="tel:0981451451">`（支援手機一鍵撥號）
    - LINE：`<a href="https://line.me/ti/p/~tseng0220">`（支援一鍵呼叫 LINE 加入好友）
    - 社群：Facebook、Threads 原生外部連結（具備 `rel="noopener"`）
    - 導覽：頁首與頁尾配置站內章節平滑捲動錨點（`#top`, `#directions`, `#public`, `#daily`, `#candidate`, `#contact`）。

## 9. 影像製作 SOP

影像在編修前必須先判斷「內容、證據屬性、頁面用途」，再決定修改方式。

### L1 — Restoration

用於歷史照片、紀實照片、證件等。

允許：

- 曝光修正
- 色溫／色偏修正
- 降噪
- 壓縮失真改善
- 清晰度提升
- 適度裁切與網站比例輸出

禁止：

- 改寫證件文字
- 重演歷史事件
- 新增不存在的人物／物件
- 改變事件事實

### L2 — Editorial Adaptation

用於真實素材的網站構圖適配。

可依 Desktop／Tablet／Mobile 調整裁切、留白與視覺焦點，但仍需保留原事件與人物真實性。

### L3 — Creative Generation

用於 Hero、政策情境、品牌視覺、地方氛圍等創作素材。

可以重繪與改變姿勢／構圖，但不得讓創作圖冒充真實服務證據。

### Images

本專案後續生圖／編修以 **ChatGPT Images 2.5** 工作流為基準。

## 13. HD 素材與 Sprite 問題

V6.1 初次部署時，為降低傳輸大小曾將大量照片製成極低容量 Sprite。

實際上線後發現：

- Hero 約 7–11 KB
- People Sprite 約 2 KB
- Actions／Local／History／Service Sprite 也只有數 KB

結果在大螢幕與 Retina 裝置被放大後明顯模糊。

### 正式修正決策

照片型素材 **取消 Sprite 化**。

Sprite 僅適合小型 icon／UI，不適合：

- 人物
- Hero
- 地景
- 政策情境圖
- SERVICE 紀實照
- 歷史照片

目前 HD 素材已重新上傳至：

- `assets/hero/`
- `assets/people/`
- `assets/actions/`
- `assets/local/`
- `assets/service/`
- `assets/history/`
- `assets/maps/`
- `assets/social/`
- `assets/ui/`

並包含 AVIF／WebP／JPG 等格式。

下一階段需把 HTML/CSS 對 `sprites/*.webp` 的照片依賴改成 HD `<picture>`／`<img>` 響應式資產。
