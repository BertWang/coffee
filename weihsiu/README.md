本目錄為曾偉修 2026 龍子里里長參選網站。曾偉修為「所以咖啡 SUOYI COFFEE」創辦人／負責人，因此網站與所以咖啡共用同一個 GitHub Repository 與網域，但必須以獨立子目錄方式並存。

### 已定案

- 所以咖啡既有網站 **不得修改、覆蓋或破壞**。
- 曾偉修網站固定放在 `/weihsiu/`。
- 公開網址固定為 `https://suoyicoffee.com/weihsiu/`。
- 部署只使用 **GitHub + GitHub Pages**。
- **不使用 Vercel**。
- 內部專案代號使用 `XIU`。
- 網站年份統一為 **2026 選舉**。
- 全站對訪客的第二人稱一律使用敬語 **「您」**，不得使用「你」。
- 「2035」不是本專案既定正式政策名稱；未經再次確認不得自行加入。

## 2. 網站真正目標

網站不是傳統競選海報搬上網路，而是讓第一次認識曾偉修的訪客，在短時間內理解：

1. 曾偉修是誰。
2. 為什麼投入龍子里。
3. 有哪些人生、工作、創業與公共服務經歷。
4. 對龍子里的理解與行動方向。
5. 過去實際處理過哪些居民問題。
6. 如何聯絡與反映問題。

設計應建立「可信任、有效率、有地方生活感」的印象，避免滿版政治口號、過度宣傳或與一般候選人海報網站同質化。

## 8. 人物素材規則

曾偉修人物是全站最重要的識別資產。

### 原則

- 人物一致性優先。
- 使用已確認的人物 Master 作 Source of Truth。
- 素材角度、比例、姿勢或畫質不適合版位時，可使用 Images 2.5 做重繪／編修／動作調整。
- 不因網站版位需求任意改變人物身份特徵。
- 不從 AI 衍生圖反向當成新的身份 Master。
- Hero、About、Contact、行動圖中的人物需要做一致性 QC。
- 正式網站素材需要依 Desktop／Tablet／Mobile 主動準備適合比例，不要求同一張圖片硬裁所有裝置。

## 9. 影像製作 SOP

影像在編修前必須先判斷「內容、證據屬性、頁面用途」，再決定修改方式。

### L1 — Restoration

用於歷史照片、紀實照片、證件等。

允許：

- 曝光修正
- 色溫／色偏修正
- 降噪
- 壓縮失真改善
- 清晰度提升
- 適度裁切與網站比例輸出

禁止：

- 改寫證件文字
- 重演歷史事件
- 新增不存在的人物／物件
- 改變事件事實

### L2 — Editorial Adaptation

用於真實素材的網站構圖適配。

可依 Desktop／Tablet／Mobile 調整裁切、留白與視覺焦點，但仍需保留原事件與人物真實性。

### L3 — Creative Generation

用於 Hero、政策情境、品牌視覺、地方氛圍等創作素材。

可以重繪與改變姿勢／構圖，但不得讓創作圖冒充真實服務證據。

### Images

本專案後續生圖／編修以 **ChatGPT Images 2.5** 工作流為基準。

## 13. HD 素材與 Sprite 問題

V6.1 初次部署時，為降低傳輸大小曾將大量照片製成極低容量 Sprite。

實際上線後發現：

- Hero 約 7–11 KB
- People Sprite 約 2 KB
- Actions／Local／History／Service Sprite 也只有數 KB

結果在大螢幕與 Retina 裝置被放大後明顯模糊。

### 正式修正決策

照片型素材 **取消 Sprite 化**。

Sprite 僅適合小型 icon／UI，不適合：

- 人物
- Hero
- 地景
- 政策情境圖
- SERVICE 紀實照
- 歷史照片

目前 HD 素材已重新上傳至：

- `assets/hero/`
- `assets/people/`
- `assets/actions/`
- `assets/local/`
- `assets/service/`
- `assets/history/`
- `assets/maps/`
- `assets/social/`
- `assets/ui/`

並包含 AVIF／WebP／JPG 等格式。

下一階段需把 HTML/CSS 對 `sprites/*.webp` 的照片依賴改成 HD `<picture>`／`<img>` 響應式資產。

## 16. 網站 QC 標準

正式 `/weihsiu/` 上線後需重新做第二輪 QC。

### 視覺

- Hero 人物比例
- 人物一致性

### Responsive

至少檢查：

- Desktop 1920／1440
- Tablet 1024／768
- Mobile 430／390／375

重點：

- 不得橫向溢出
- 不得裁錯人物臉部
- 圖片不得糊
- 手機版不可只是桌機縮小版
- 文字不得過密

- 全站「您」，不得出現對訪客稱「你」
- 2026
- 候選人身分與文字一致
- 電話／LINE／社群正確
- 未確認資料不得寫成事實
- 「2035」不得自行復活

### 功能

- 電話撥號
- LINE
- Facebook
- Threads
- Anchor
- Mobile Menu
- 外部連結
- 圖片／CSS／JS 無 404

### 判定

- PASS：直接保留
- TUNE：CSS／裁切／字級等小調整
- REWORK：區塊需要重排
- REPLACE：素材需更換
- FAIL：不得上線
